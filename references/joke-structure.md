# 笑點拆解（鉤子／鋪墊／包袱／tag）

90 秒語音小品是 **一個 bit**，不是春晚 10 分鐘小品，也不是 SNL 冷開場。先拆結構，再寫對白。

## 最小單位

脫口秀／小品底層都是兩段式：

- **鋪墊 setup**：告訴聽眾該期待什麼
- **包袱 punch**：給別的東西

預期與實際的落差 = 笑聲大小。落差太小是微笑；太大且對不上是困惑，不是笑。

來源：Stand-Up Writer《鋪墊、包袱、tag: 段子結構 101》（2026-05-03）https://stand.app/zh/guides/joke-structure-101

## 前提 ≠ 鋪墊

| | 是什麼 | 例子 |
|---|---|---|
| 前提 | bit 背後那句觀察 | 「客服說自己是人工，其實流程還是機器人。」 |
| 鋪墊 | 前提裡某一槍的具體場景 | 「您好，這裡是人工客服，我是真人。」 |

一個 90 秒 bit = **一個前提 + 3～5 個鋪墊**。每個鋪墊都在重複同一個前提，觀眾會覺得你沒在講段子。

## 鉤子（前 8 秒）

語音沒有臉、沒有舞台定裝。前兩句必須：

1. 具體（誰、在哪、要幹嘛）
2. 安裝預期（聽眾開始猜下一步）
3. **還不要翻轉**

弱鉤子：「我跟你講一件好笑的事。」／「本篇講述一個古人……」
強鉤子：「您好，這裡是人工客服，我是真人。」
強鉤子（說書）：「欸，你有沒有遇過那種人。漂亮到不正常，好到讓你不敢問第二句。」

語音沒有臉。前兩句必須讓人覺得「這在講我的生活」，不是在上課。

賀瓏／單口入門常從 one-liner 練「一句話裡完成鋪墊＋翻轉」。90 秒小品的鉤子只做鋪墊，把翻轉留給後面。

## 鋪墊裡零笑話

Humor Blueprint 的硬規則：setup 裡不要塞小笑。小笑會洩壓，包袱就炸不開。

來源：https://funnymuscle.com/write-better-jokes-without-ruining-the-setup/

中文社群同一句話：

> 段子 = 鋪墊 + 笑點  
> 鋪墊引出故事 1，讓你產生目標預期；笑點是對故事 1 的再解讀，揭示合理但意外的故事 2。

來源：Xmind 投稿《脫口秀觀看指南》拆李雪琴段子 https://xmind.cn/blog/how-to-be-a-professional-comedian

李雪琴式再解讀（社群常引）：別人討厭你 → 預期「我是不是做錯」→ 翻成「沒關係，反正我也不喜歡你」。90 秒客服稿用同一骨架：預期「終於接到人」→ 翻成「真人被訓練成機器人」。

## 三的法則

前兩項建立正常模式，第三項打破。

> 我喜歡長長的散步、燭光晚餐、收到驅逐通知。

兩個不夠鎖定模式；四個在包袱前洩氣。90 秒只用 **一次**。三分鐘內用兩次，觀眾會聽到「模式要來了」。

來源：Stand-Up Writer 同上；英文寫作原則 https://en.wikipedia.org/wiki/Rule_of_three_(writing)

語音小品裡的三次：轉接訂單組 → 轉接取消組 → 轉接「人工主管」還是同一個人。

## 詞序 = 紙上的演法

好笑的詞放句末。

弱：我在機場買了一份沙拉——它要四十歐元。  
強：在機場，我用四十歐元買了一份沙拉。

現役喜劇人修稿第一刀：砍掉好笑那個詞前面的廢話。多數段子比應有的長 30%；先剪鋪墊，不剪包袱。

## tag 與 callback

- **tag**：包袱落地後立刻第二擊，不重開鋪墊。因為聽眾已經在笑，門檻較低。
- **不要硬 tag。** 硬 tag 比沒有更糟。
- **不要解釋包袱。** SNL／Reddit 寫手共識：解釋笑話就是殺笑話。
- **callback**：回收開頭鉤子。90 秒結尾最穩的一招。

Costco 教學例（Stand-Up Writer）：  
包袱：「於是我就被 Costco 拉黑了。」  
tag：「是真的 Costco。不是隱喻裡的 Costco。」

## 良性違規

McGraw & Warren（2010）Benign Violation：既違反常理，又不具危害，兩者同時發生才會笑。時機、節奏、斷句決定「同時」。

客服荒謬、自我打臉、系統拒絕道歉 = 良性。攻擊弱勢、靠歧視落點 = 不是這條 skill 的範圍。

## 觀察還不是段子

「客服是不是很煩」是觀察，在段子開始的地方就結束了。段子要拿這個觀察，用一個具體翻轉兌現。沒有翻轉，就只是沒有包袱的鋪墊。

練習（社群常用）：

1. 挑一個沒成立的觀察，強迫寫五個不同包袱。第五個通常才可用。
2. 成立的段子再砍三個字。砍不掉才夠緊。
3. 同一個包袱換一個鋪墊，指向完全不同的落點。

## 90 秒時間軸（語音）

```
0:00  鉤子          安裝「她是真人」
0:08  鋪墊          客人只要取消訂單（零笑話）
0:22  誤導          心情指數（開始偏離，尚未翻轉）
0:40  三的法則      轉接、轉接、還是她
1:02  包袱          真人被訓練成機器人
1:15  tag           本系統不支援道歉功能
1:22  callback      您好，這裡是人工客服，我是真人
1:30  停
```

春晚小品（余欽南／郭江濤《聽懂了嗎》、密包袱《幫你忙》）是 8–12 分鐘、多角色、舞台調度。那些是密度參考，不是時長模板。美式 sketch 更快堆笑、較不求完整故事；本 skill 的 90 秒走「一個前提講完」。

## 對 T8 的額外約束

結構對了還會被引擎殺死：

- 指示寫進對白 → 模型把「用甜美的聲音」唸出來
- 一段兩人 → 聲線互污染
- 長文言／四字疊詞 → 音素糊成諧音
- Turbo LoRA → 有音量沒口齒

所以拆稿之後還要再切成「一人、≤40 字、5–15 秒」的 T8 段。

## 生活化用詞（說書／旁白）

旁白是給耳朵聽的。單詞標籤（平、白、輕、乾、兇）聽起來像在點名，不像在說故事。

已驗證修正（2026-08-20《畫皮》）：

- 很平 → 很平順
- 臉色很白 → 臉色很白皙
- 其餘完整對照見 `story-stillcut.md`

10 分鐘說書不要套上面的 90 秒硬軸。鉤子／誤導／證實／callback 還在，時長跟旁白走。
